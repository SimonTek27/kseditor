# Product identity

| Name | Role |
|------|------|
| **ksim** / **SimulatorApp** | Independent open-source racing simulator |
| **ksengine** | Generic simulation engine |
| **kseditor** | Editor (Qt) |

## Rules
1. Public identity = **ksim** (or the repo product name), not a commercial third-party sim.
2. Code may implement **compatible file and memory layouts** for interoperability.
3. Comments and docs describe *formats* and *layouts*, not “we are X clone”.
4. Optional content roots may point at user-chosen folders; no mandatory third-party install for the engine to run.
5. Trademarks of other companies are not used as product names in UI, packages, or primary docs.
